# AI Skills — 10 camera moves for AI video

Ten Claude skills that turn a camera move into a ready video-model prompt: the move, the effect and the action stay fixed, while location, time, light and characters are yours to swap. Built for commercial video for social media and websites, and made to work with [HyperFrames](https://hyperframes.heygen.com) by HeyGen.

Десять скилов для Claude: каждый превращает движение камеры в готовый промт для видеомодели. Камера, эффект и действие зафиксированы, а локацию, время, свет и персонажей вы меняете под свой ролик. Инструкции внутри скилов — на русском, шаблоны промтов — на английском.

## Install

```bash
npx skills add Rjyarik/ai-skills
```

Works with Claude Code and other agents that read skills. On claude.ai, download a skill folder and upload it in Settings → Capabilities → Skills.

## The skills

| Skill | Move | Best for |
| --- | --- | --- |
| `camera-crash-zoom` | Locked camera, violent zoom from wide to extreme close-up in a fraction of a second | Punchlines, reactions, a product detail |
| `camera-dolly-zoom` | Dolly back while zooming in: the subject holds size, the background stretches (vertigo) | A moment of realisation, the customer's pain |
| `camera-orbit` | 180° circle around the subject at chest height | Hero shots of a founder, expert or product |
| `camera-crane-down` | Descends from high above the location to eye level | Opening shots, establishing a place |
| `camera-fpv-drone` | One continuous dive, low skim and pull-up onto the subject | Travel, hotels, real estate, events |
| `camera-rack-focus` | Still camera, focus shifts from a foreground object to the person behind it | Linking a product to a person |
| `camera-low-angle-tracking` | Knee-height camera moving backward as subjects walk at it in slow motion | Launches, team reveals, big announcements |
| `camera-top-down` | Straight-down view, slow clockwise rotation and slight descent | Tables, food, unboxing, maps |
| `camera-handheld` | Operator running behind the subject with organic shake | Energy, urgency, behind the scenes |
| `camera-dolly-out` | Fast pull back from a close-up to an extreme wide reveal | Revealing scale: a team, a catalogue, a system |
